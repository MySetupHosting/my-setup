# My-Setup



The most safe Windows installing framework.



## Requirements



You should have:



* Git
* The configurator (on this repo)
* The script (on this repo)



## Configurating it



Sign in with your GitHub account on Git. Then, put the scripts on a path you can use. Open PowerShell on it and execute:



~~~
.\\install.ps1
~~~



The script will automatize the configuration.



## Handbook



### PART 1: SIMPLE USE



#### Chapter 1: Installing



You can install a repo by:



~~~
my-setup install test
~~~



Replace test with the needed repository.



#### Chapter 2: Making avaibility on Start Menu



Make a shortcut of the file on the folder of your Windows device. You can google it.



#### Chapter 3: Uninstalling



Manually delete it, the folder, and the shortcut, if you made it.
